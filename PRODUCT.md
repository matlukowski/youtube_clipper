# YouTube Clipper

<!-- impeccable:product-schema 1 -->

## Platform

web

The product being promoted is a Windows desktop application. This project is its landing page.

## Stack

Next.js landing page, hosted on Vercel (user decision).

## Users

People who need to save a selected fragment of a YouTube video to their Windows computer.

## Product Purpose

Select and save a fragment of a YouTube video. The user can export it with sound or without sound.

## Operating Context

The application is distributed as a Windows `.exe` installer. The landing page should offer a direct download and a link to the GitHub repository, where the installer is also available.

## Capabilities and Constraints

- Cut a selected fragment from a YouTube video.
- Save the fragment with or without sound.
- Save the resulting fragment to the local hard drive.
- Landing page language: Polish.
- Product is free to download according to the user.
- The provided installer reported product version 1.1.5. A matching source archive was supplied and is now preserved under `desktop/` in this project. The next release is 1.1.6.

## Brand Commitments

- Name: YouTube Clipper.
- Landing page tone: expressive and aimed at creators.

## Evidence on Hand

- `YouTube Clipper.exe` was the provided Windows installer.
- Desktop application source is present under `desktop/`.
- No verified application screenshots, testimonials, or usage numbers were supplied.

## Product Principles

- Explain the core action immediately.
- Make the Windows download easy to find.
- State the sound choice plainly.
- Keep claims within confirmed capabilities.
