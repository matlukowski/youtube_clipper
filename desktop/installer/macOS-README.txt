YouTube Clipper 1.1.6 — macOS 15 lub nowszy

arm64: Mac z procesorem Apple (M1, M2, M3 i nowsze).
x86_64: Mac z procesorem Intel.
Typ procesora sprawdzisz w menu Apple > Ten Mac.

Przeciągnij YouTube Clipper do folderu Applications (Aplikacje).
Uruchom aplikację z tego folderu i wysuń obraz dysku.

To wydanie nie ma certyfikatu Developer ID ani notaryzacji Apple.
macOS może zablokować pierwsze uruchomienie. Po próbie otwarcia
przejdź do Ustawienia systemowe > Prywatność i ochrona > Otwórz mimo to.
Nie wyłączaj Gatekeepera ani innych zabezpieczeń całego systemu.

Aplikacja zawiera Python, Node.js i FFmpeg. Niczego nie musisz
instalować osobno. Klipy i ustawienia są zapisywane w:
~/Library/Application Support/YouTube Clipper/
Folder klipów możesz zmienić w aplikacji.

Licencje dołączonych narzędzi: YouTube Clipper.app/Contents/Resources/third_party.
Źródła FFmpeg i x264 oraz skrypt budowania są dostępne w wydaniu GitHub:
https://github.com/matlukowski/youtube_clipper/releases/tag/v1.1.6
