# YouTube Clipper visual system

The approved direction is a calm creator workspace after dark. Precise timing graphics carry the product story. The palette is shared by the landing page and Windows editor.

## Color tokens

| Role | Landing | Windows app |
| --- | --- | --- |
| Primary canvas | `#101728` | `#101728` |
| Raised surface | `#18233a` | `#1a2439` |
| Main text | `#f8f9ff` | `#f3f5ff` |
| Secondary text | `#b9c4de` | `#bbc5dc` |
| Selection and action | `#9d95fa` | `#8b82ea` |
| Dark ink on action | `#101728` | `#101728` |

The landing has a pale reading area (`#f2f4ff`) for the three-step explanation. The editor remains dark throughout so video frames and the selection range stay legible.

## Typography and layout

- Landing: Manrope, bold display with a restrained negative tracking; clear 14–16 px controls and body text.
- Windows editor: Segoe UI for native readability and continuity with existing controls.
- Shared motif: a selected clip range between violet handles, with exact ruler ticks and a waveform. It is an illustration on the landing, a functional timeline in the editor.
- Buttons use a solid violet fill with dark text. Text links remain visibly underlined or bounded by a bottom rule.

## Motion and interaction

Only controls move on hover, by two pixels; reduced-motion preferences remove transitions. Focus rings stay visible. The selected range is the one visual highlight in both surfaces.
